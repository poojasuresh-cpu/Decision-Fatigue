# Decision-Fatigue

# Overview:
Decision Fatigue Guard is a productivity tool designed to reduce cognitive overload by filtering and prioritizing decisions. It helps users focus on high-priority tasks and minimizes mental fatigue through a logic-based decision filtering system.
# Features:
Prioritizes tasks based on user-defined logic
Reduces cognitive overload and mental fatigue
Provides actionable insights for better decision-making
Simple interface for tracking and managing daily decisions
# Technologies Used:
Python
Algorithm Design
Logic-Based Decision Systems
Productivity Tools
# How to Use:
Clone the repository.
Install required Python packages from requirements.txt.
Customize decision rules as per your requirements.
Run the main script to start using the tool.
